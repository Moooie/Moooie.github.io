Personal Portfolio Website & Interactive Web Games Showcase by **Ari Satriya (Moooie)**.

## 🚀 Live Website
Kunjungi website langsung di: **[https://moooie.github.io](https://moooie.github.io)**

## 🎮 Game Interaktif yang Tersedia:
1. **[Escape The Backrooms: Liminal Horror Co-op (3D)](backrooms.html)**: Game horor 3D Level 0 dengan sistem persembunyian di loker & tahan napas, entitas The Bacteria, peningkatan atribut survivor [TAB], skill aktif [Q, Z, X], serta Co-op multiplayer P2P WebRTC.
2. **[Sunset Drift Masters (3D Car Racing)](racing.html)**: Game balapan mobil 3D arcade dengan mobil Drift Master RX-8, 5 pembalap NPC cerdas, suasana senja keemasan, dan kotak power-up di sirkuit.
3. **[Minecraft Web 3D Edition](minecraft.html)**: Klon 3D voxel sandbox dengan sistem tebang pohon, penambangan blok, crafting 2x2 & 3x3, pedang, busur panah, serta inventory lengkap [E].
4. **[Stickman: Shadow Reckoning (2D Action RPG)](game.html)**: Game aksi platformer 2D dengan 2 senjata (pedang & panah), mekanik dash/dodge berstamina, dan cerita bercabang.
